## ゼミ資料との違い

| | ゼミ（論文・輪講） | 修論発表 |
|---|---|---|
| 言語 | 英語（ノートに日本語訳） | 日本語 |
| 和文フォント | ヒラギノ角ゴ W4 | 游ゴシック Medium（英数は Arial） |
| 表紙 | タグ・タイトル・著者・会議名・日付 | タグ `修士論文 中間発表資料`、日本語タイトル＋英語タイトル（小さく）、所属（大学院・専攻・コース・研究室）、氏名（ローマ字併記）、日付（`2026年10月13日（火）`） |
| 扉・目次 | あり | なし（枚数が少ない） |
| 枚数 | 90分で 40〜50 枚 | 7分で 12〜13 枚 |
| 最後 | References | 研究業績（国際会議・国内学会・ワークショップ。自分の名前を赤太字） |

日本語スライドは `deck.FONT_EA = "Yu Gothic Medium"`、`deck.FONT_LATIN = "Arial"` に差し替えてから組む。

## 1ページの組み立て

- 上から読めば話が通る順：**主張（リード）→ 構成の説明 → 具体例の図 → 次のページへの問い**
- リード文は、そのページの主張（課題なら課題）を1文で言い切る。帯や図の番号（②〜④）に頼らない
- 実験設定のページはリード帯なし。「共通設定：」→「評価実験①」「評価実験②」（紺地に白字の角丸ラベル）の順
- 左の文と右の図の高さを揃え、図は大きめに置く
- 図は吹き出しや枠で、どの要素の話かを結ぶ（帯の④から右の図へ吹き出し）
- 課題は赤字＋淡い赤の箱、次への問いは太い黒の右矢印＋太字（「➡ 通信路を増やして、並列に送れないか？」）

## 文字

- 長所・課題は1〜2行。まだ説明していない用語（「ブロック」「席」など）は使わない
- 表の見出しは短く（「n=1 からの削減率」→「削減率」＋表の下に注）
- 信頼区間の帯は「色付きの帯／陰影部：95%信頼区間」（「網掛け」と言わない）
- ラベルの先頭は大文字（「Good arm」）、文中は小文字（good arm）
- 推定値はハット（$\hat M$）、good arm はチルダ（$\tilde k$）
- 数を不等式で書かない、あいまい語には範囲を書く

## 図

- 段階の帯：`chevrons()` で ①〜④ を横に。対象の段は緑（`pale-green`＋`green`）、課題の段は赤。
  帯の下に「Good arm $\tilde k$ 1本で通信」を 16pt で
- 例の図：リーダー・サブリーダー・フォロワーをプレイヤーアイコンで縦に並べ、通信の向きを赤矢印、
  待機中は「⏸ 待機中」の小箱
- 上界の比較：既存手法と提案手法の式を上下に並べ、項の下に紺の括線と「探索項」「初期化項」「通信項」、
  変わった係数に淡青・淡紫のマーカー
- 実験の図は大きく。右に「n = 4 が最良の並列数」などの注記を赤矢印で
