# 説明図の語彙

本人がわかりやすい説明のために使っている図の作り方。寸法は実物から測った値。
**図は PowerPoint の図形と `assets/icons` の画像で描く。** 論文の実験グラフ以外を画像にしない。

## 1. プレイヤーと腕（バンディットの基本図）

```
Arm k (K = 4)      [slot] [slot] [slot] [slot]        ← 腕は 0.86×0.46（大きくするとき 1.05×0.57）
                     ↑   ↗      ↑                     ← 紺 3.5pt の矢印（プレイヤー→腕）
Player m (M = 3)    🧍     🧍     🧍                   ← 人は 0.26×0.66（大 0.32×0.81）
State s_m          s₁=0   s₂=0   s₃=3                 ← 値は数式。変わった値は赤枠、地は黄
```

- 行ラベルは左端 0.54in から 20pt（`**Arm** $k$ $(K = 4)$`）。図の列は 2.0in 以降
- 腕の番号（1, 2, …）は腕の上に数式で中央揃え
- 腕の間隔は 1.24in 前後（腕 0.86 + 隙間 0.38）。プレイヤーは引く腕の真下
- プレイヤーの下に状態や報酬（`$r=0$`）を数式で。変わった値は `frame()` で赤枠
- 衝突：**腕のアイコンに重ねない。** 2 人を離して置き、まっすぐの矢印と斜めの矢印を同じ腕の下端に集め、
  矢印が集まる所（腕の下端のすぐ下）に爆発図形を置く。`collide((腕の x, 腕の y), [P1 の x, P2 の x])` がこの型を描く
- 固定（その腕に落ち着いた）：**固定されたプレイヤーの左隣**に `lock()`（0.56×0.64）。腕の上には置かない
- 図を描いたら「この図だけで、誰が・どの腕を・どうしたか言えるか」を確かめる（2026-10-15 本人の修正。
  `assets/reference/スライドデザイン変更点まとめ.pptx` の 3・4 枚目が変更前と変更後）
- 通信・合図：送信者と受信者を `warm` の「Sender」「Receiver」ラベルで区別し、
  `η = 1 → data : 1` のような吹き出しを角丸の細枠で付ける
- 待機中・関係ないプレイヤーは矢印を `line-gray` にする

コード例：

```python
xs = [3.0, 4.24, 5.48, 6.72]                     # 腕の左端
for k, x in enumerate(xs, 1):
    s.slot(x, 3.6); s.clabel(x + 0.43, 3.15, f"${k}$", 18)
px = [x + 0.30 for x in xs[:3]]                   # プレイヤーの左端（腕の中心 - 0.13）
for m, x in enumerate(px, 1):
    s.player(x, 5.0)
s.arrow(px[0] + 0.13, 4.95, xs[0] + 0.43, 4.15)  # プレイヤー頭上→腕の下端

# 衝突の例：P1（腕 1 に固定）と P2 が同じ腕 1 を引く。P2 は腕 2 の下に離して置く
cx, py = s.collide((xs[0], 3.6), [xs[0] + 0.30, xs[1] + 0.30])
s.lock(xs[0] + 0.30 - 0.6, py - 0.45)            # 南京錠は P1 の左隣
```

## 2. 規則の箱（擬似コード）

- 右側 8.0〜12.66in に `code(x, y, w, lines, hl={行: "pale-blue"})`
- 灰色 `BFBFBF` の細枠の角丸、16pt。キーワード `if` `then` `else` `for` `do` は `{red-n:if}`
- いま効いている行に淡青 `D1E1EA` か黄 `F6EAC3` の帯。ページを進めるごとに帯を動かす
- コメントは `# keep this state ...` を `warm` で
- 原論文のアルゴリズム全体を見せるときは、行の文言を一字一句そのまま。数式は `$...$`

## 3. 時刻の帯

- 左上の見出し `**Example:**` の右に `tbox(x, y, "$t = 3$")`（細枠の小箱）
- 右上に時刻の帯：`t` の行（0 1 2 3 …）と、ブロックの区切りを表す表（緑 `E4F6DD` の地）。
  現在の時刻の上に紺の下向き矢印（`shape("downArrow", ...)` 0.36×0.38）
- 帯の下に 16pt で `Selection Phase` / `Communication Phase` のような区間名

## 4. 表で状態を追う

- 縦罫なしの表（`table()`）。見出し行は紺地に白字、見出し下と最終行の下に紺 3pt
- 注目の列は黄 `F6EAC3`、枠は `amber`
- 表のマスの値を丸で囲む（`ring()`、赤 2.25pt と紺 2.25pt で2種類を区別）
- 時刻×アームの格子で「誰がどこを引いたか」を見せると、動作が一目で追える

## 5. 分類の木・階層

- 角丸の箱（地 `lead`、枠 `ink` 0.75pt、16〜18pt）を、紺 1.5pt の矢印で左から右へ枝分かれ
- 注目の葉（本論文の設定）は赤字・赤枠（`pale-red` の地）
- 葉の右に、その分類で観測できる量を数式で並べる
- 「難易度」など順序のある軸は右端に縦の矢印（上が易しい）とラベル

## 6. 段階・流れ

- **縦の段階**：`steps(x, y, w, [(見出し, 説明), ...], color)`。❶ 28pt＋小さな下向き三角。
  初期化系は緑、本体は青（本人の Overview of the Algorithm の型）。同じ Overview を
  段階が変わるたびに再掲する
- **横の段階**：`chevrons()`（先頭 homePlate、以降 chevron）。完了・対象の段は `pale-green`＋`green`、
  課題の段は `pale-red`＋`red`、今は関係ない段は灰色。帯の下に 16pt で補足（`Good arm $\tilde k$ 1本で通信`）
- **Flow of Section**：3 段を横の線でつなぎ、点（●）を置き、見出しと説明を上下に。
  今の段だけ赤 `D14B46`、他は `gray`

## 7. 対応づけ

- 吹き出し `callout(x, y, w, h, 文, tip=(先の x, y))`：白地＋紺の細枠、16pt
- 中かっこ `brace()`：表の列のまとまり（`K`）、プレイヤーのグループ
- 数式の項のマーカー `mark()`：黄・緑の淡色を項の背面に。本文の語と同じ色にして対応を示す
- 数式の項の下に `\underbrace{...}_{\text{Exploration Regret}}` で名前を付ける（本人の Theorem のページ）

## 8. 比較（2つの手法・2つの設定）

- 左右に同じ形の図を並べ、中央に `line-gray` の縦の区切り線
- 見出しは紺地に白字の小さな帯（`In Homogeneous settings`）か、太字＋色
- 違う所だけ色を変える（赤い矢印、灰色に落とした矢印）

## 9. 実験の図

- 論文の図は PNG で貼る（PDF の図は `pdftoppm -png -r 200 -singlefile` で変換）
- 大きく置く。2枚なら 1枚 5.8in 幅前後、横に並べて 0.54〜12.66in を使い切る
- 図の下に `Figure 2:` 太字＋キャプション 16pt。読み取ってほしい所に赤矢印・赤枠・吹き出し
- 図の中に設定が書かれていないときは、行・列の見出しを図形で付ける

## 10. 引用

- `quote(x, y, w, 文, source="[Trinh & Combes, 2021, Sec. 2.5]")`：淡い面＋左に紺の縦線
- 原文は一字一句。省略するときは `...` を明示。訳はノートに書く
- 証明がない・予想にすぎない、という主張は必ず原文の引用で示す

## 使わないもの

- 小さすぎるアイコン（文字化けに見える）、絵文字、クリップアート
- 影・グラデーション・3D・ワードアート
- 装飾だけの図（内容と関係ない写真・イラスト）
- 原論文の図を「説明図」として流用すること（動作例は自分で図形で描く）


## 8. 箇条書きと囲み（箱を使いすぎない）

本人の修正（2026-10-15、`assets/reference/スライドデザイン変更点まとめ.pptx`）。Claude は何かあるごとに
箇条書きを塗りの角丸の箱に入れる癖がある。本人は箱を外して文字だけにした。

| 見せたいもの | 本人の形 | 部品 |
|---|---|---|
| 注意点・根拠などの箇条書き | 色つき見出し（20pt 太字）＋文字だけの箇条書き。要点は見出しと同じ色の太字、行頭の • も同じ色。行間 120%、段落の後 12pt | `points()` |
| 対比（注意 / 根拠） | 上の形を左右に 2 列（見出しの色を赤と緑に分ける）。箱で囲まない | `points()` ×2 |
| 短い結論 2〜3 個（良い場合 / 悪い場合） | 白地・色つき 2.25pt の枠、見出しを枠の上辺に載せる、本文 18pt 中央・行間 150% | `fieldset()` |
| 1 つの主張の強調（定義・結論） | 塗りの箱 1 個（淡い色）。1〜2 文まで | `box()` |

- 塗りの箱は 1 枚に 2 個まで（リード帯を除く）。`lint.py` が 3 個以上と「箱の中の箇条書き」を警告する
- 年表・文献の紹介も、カードの箱に詰めない。年と著者を色つき太字の見出しにして、下に 1〜2 行の文字を置く
